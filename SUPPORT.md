# Support

KuberWeaver is an early-stage prototype maintained by one person in their own
time. There is no support team, no service level agreement and no guaranteed
response time. Read this page before opening an issue so your report has the best
chance of a useful answer.

## Where to ask

- Bugs, defects and regressions: GitHub Issues with the "Bug report" template.
- Feature ideas and capability gaps: GitHub Issues with the "Feature request"
  template.
- New workload bricks or plugins: GitHub Issues with the "Plugin submission"
  template.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md). Never open a
  public issue for one.

GitHub Discussions is not enabled on this repository yet, so questions that would
belong there go to Issues for now. A Discord server may be added later; there is
no invite link at the moment. Do not send support requests by email, and do not
expect a direct message to be answered.

## What you can expect

Issues are triaged when the maintainer has time. A question may wait for weeks or
stay unanswered. There is no merge or review guarantee for contributions, and no
promise that a requested feature will be built. The README capability table is the
authoritative description of what exists and what is explicitly out of scope.

A well-formed report gets better results than a urgent one. State the commit or
version, the exact command or API call, the observed result, the expected result,
and paste logs with every secret redacted. Search existing issues first.

## What is not supported

- Commercial support, paid consulting, contracts or SLAs.
- Debugging your personal hypervisor, network, virtual machine or cloud account.
- Writing your brick, plugin or integration for you.
- Data recovery, migration or production operations on your installation.
- Anything outside the documented capability boundaries in the README.
- Requests to expose the project as a hosted service for third parties.

## Before you open an issue

Check the README capability table. Verify that the behaviour you saw is not a
documented limit, a planned and disabled feature, or a consequence of running
without the prerequisites listed in the README.
